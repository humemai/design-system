Layout

Memory is what an agent keeps beyond one prompt: what happened, what matters now, and how structured knowledge stays available over time. This paragraph is long enough to fill the measure on a wide screen, so the width of its box is the measure and not the width of the page. It is one column at every size, because prose in two columns makes a reader scroll back up for the second one, and a box with a height adds columns sideways. A line of about eighty characters in the body face is where the system settled, so the box is capped at sixty-eight zeros.
